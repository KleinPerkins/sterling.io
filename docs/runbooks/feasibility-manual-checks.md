# Remaining physical-input and desktop checks

Status: **Not run.** These checks require a person using the Mac. Automated local-handler calls and window properties are supporting evidence only. A failure keeps the corresponding feasibility gate open; do not approve the gate from this checklist alone.

## FZ-01 — input and focus

Use an empty, unsaved text document and a harmless local test window. Record the macOS build, display arrangement/scales, each result, and any unexpected action. Do not use valuable files or a live send/delete/purchase control as test fixtures.

1. Launch Sterling while typing in the empty document. Continue for 30 seconds. The insertion point stays in the document; no characters disappear, move, or land in Sterling.
2. Move the test window under the passive cat. Click a harmless control directly under the cat and in the transparent margin. Each click reaches the intended control exactly once; no care window opens.
3. Begin a text-selection drag outside Sterling's render rectangle, cross through it, and release beyond it. Selection remains continuous. Repeat in both directions and with rapid crossings.
4. Open Care explicitly. In Pet mode, stroke head/back and release. Only this visible care surface owns the gesture. Starting a drag elsewhere and entering it must not start petting.
5. During a care gesture, release outside the window, press Escape, use Hide, pause, switch to another app, and change Spaces in separate trials. Ownership and contact must stop. No cancelled event is replayed to the other app.
6. Use keyboard-only Pet/Play and Done. Space starts/stops once even when held; arrow keys move the toy only in Play; Escape closes care. Switching to another app immediately stops contact. Repeated quick mode switches do not restart a cancelled interaction.
7. Continue gentle petting until he withdraws. Re-enter immediately: accumulated satisfaction remains. Continue play, leave, and re-enter: boredom/energy are retained during this launch. These are behavior checks, not likeness approval.
8. Open VoiceOver. Check the menu, mode selector, named buttons, care-area name/help/value and custom actions. Confirm usable navigation and response feedback. The current metadata is not an accessibility acceptance receipt.

**Pass condition:** zero unintended fixture-app actions, no stolen typing focus while passive, no ownership acquired from foreign drags, and reliable cancellation. Capture actual results; leave unknown rows open.
